# EtsViewer

一个简洁高效的 ETS 考试内容查看器，支持美观格式化输出和文本导出。

## 功能特性

- 📁 **自动识别** - 自动查找 ETS 数据目录
- 🎨 **美观输出** - 将 JSON 内容格式化为易读的文本
- 📝 **多题型支持** - 支持角色扮演、图片描述、选择题、阅读理解等多种题型
- 💾 **导出功能** - 一键导出为 TXT 文件，方便分享
- ⌨️ **快捷操作** - 支持键盘快捷键翻页和缩放

## 安装

```bash
pip install -r requirements.txt
```

## 使用方法

1. 运行 `python main.py` 启动程序
2. 通过菜单「操作」→「自动选择文件夹」或「打开文件夹」加载数据
3. 在左侧列表选择要查看的作业
4. 右侧面板查看内容，支持以下操作：
   - 勾选「启用美观输出」查看格式化内容
   - 勾选「显示完整答案」查看所有参考答案
   - 点击「导出为TXT」保存内容

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + ←` | 上一条内容 |
| `Ctrl + →` | 下一条内容 |
| `Ctrl + 滚轮` | 调整字体大小 |
| 点击目录标题 | 快速切换题目 |
